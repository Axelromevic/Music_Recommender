# Music Recommender System #
<br><br>
The next code is part of a project during my studies.
The recommender music system can propose related songs based on the title and other attributes from an Amazon Music.json.gz file.
This code bases its recommendation on the similarity of songs using TF-IDF vectorization.

## 📢 Credits

This project uses data from **Amazon Review Data (2018)**, a dataset containing Amazon product reviews from May 1996 to July 2014.
